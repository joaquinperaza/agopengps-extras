Quick actions
WAS (Wheel Angle Sensor)

ADC counts per 1 degree of wheel turn. Measure by turning wheels a known angle and dividing raw count change by degrees.

Raw ADC reading at straight-ahead. Use the "Zero WAS now" button above instead of typing manually.

Corrects for Ackerman steering geometry. 100 = no correction. Adjust if the tractor drifts in curves.

Safety clamp. PID will never command beyond this. Set to your wheel-lock angle.

ADS1115 differential mode. Rejects common-mode noise. Uncheck for single-ended A0.

Flip angle sign. Check if tractor steers the wrong way.

PID / Motor drive

Corrects based on current error. Start low (0.3-1.0), increase until responsive.

Corrects accumulated error over time. Fixes steady-state offset. Start at 0, increase slowly (0.01-0.1). Too high causes slow oscillation. Leave 0 if not needed.

Opposes rapid error change — brakes the motor before it reaches the target. Prevents overshoot with fast/strong motors. Start 0, increase (0.5-5.0) until overshoot stops.

Maximum PWM duty (0-255) when steering error is large.

PWM duty when error is small. Ramps from low to high over 5 degrees.

Minimum PWM to overcome motor stiction. Set to lowest duty that makes your motor move.

Error below this = motor stays still. Prevents hunting. Start 1.0, raise if motor chatters.

Flip PWM sign to cabin node. Check if motor turns the wrong way.

IMU

Enable BNO085 for heading and roll (PGN 253). Disable if no BNO connected.

Tears down Wire1 and does full bus recovery + BNO re-init. WAS will glitch for ~1 second. Only use if BNO is stuck and soft retries aren't working.

Probes all addresses on the STEMMA QT bus. Expected: 0x48 (ADS1115), 0x4A or 0x4B (BNO085).
